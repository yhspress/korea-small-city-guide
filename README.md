# Korea Small City Guide

日本人旅行者向けの韓国地方都市ガイドです。  
일본인 여행객을 위한 한국 소도시 여행 홈페이지 독립 프로젝트입니다.

## 表示ルール / 표시 규칙

- 日本語を基本にし、地名・料理・宿泊施設・列車名は韓国語を併記
- 韓国語の文字サイズは日本語の約50%
- 地図上の都市ピンは緯度・経度データで配置
- 観光スポットはGoogle Mapsボタンで接続
- 予約リンクはTrip.com日本向けページに統一
- 広告・アフィリエイト表記を明示
- 関連旅行情報: [SOTO KOREA](https://sotokorea.com)

## 確定データ / 확정 데이터

- `data/affiliate-links.json`: 항공권, 호텔, 패키지, KORAIL, 체험, eSIM, 공항 픽업, 렌터카와 도시별 제휴 URL
- `data/cities.json`: 13개 지방 도시 좌표, 한·일 지명, 도시별 관광지 2곳과 Google Maps URL

## 公州 / 공주

- 서울 출발 노선만 사용
- 용산–공주 노선은 제외
- 공주역에서 도심까지 버스·택시 환승 안내

## 慶州 / 경주

- 서울–경주와 부산–경주 노선 모두 제공
- 주요 관광지: 불국사, 대릉원
